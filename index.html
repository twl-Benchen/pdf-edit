    使用說明

    基本流程

    1. 拖放或選擇 PDF／圖片（可一次多個，也可 Ctrl+V 貼上截圖）。
    2. 在右側縮圖中拖曳調整頁面順序（手機請長按後拖曳）；點縮圖可選取，Shift+點選可連續選取。
    3. 用工具列旋轉、複製、刪除、插入空白頁；左側檔案清單可拖曳調整整份檔案順序。
    4. 視需要設定浮水印、頁碼、文件資訊，然後按「下載 PDF」。

    快速鍵

    • Ctrl+Z 復原、Ctrl+Y 重做
    • Ctrl+A 全選、Esc 取消選取
    • Delete 刪除選取頁、R 向右旋轉選取頁
    • 雙擊縮圖或按 🔍 放大預覽，預覽中可用 ← → 切換

    如何確認檔案沒有被上傳？

    • 網頁只會從 cdnjs 下載兩個開源元件庫（pdf-lib、pdf.js）的程式碼，你的檔案不會被送出。
    • 自己驗證：頁面載入後關掉 Wi-Fi／拔網路線，工具一樣能合併與下載。
    • 或按 F12 打開開發者工具的「Network／網路」分頁，加入檔案與下載時不會出現任何上傳請求。
    • 全部程式碼都在同一個 index.html 裡，可以直接打開檢查。

    限制

    • 不能修改 PDF 內原有的文字內容。
    • 有開啟密碼的 PDF 需輸入密碼；有權限限制（加密）的 PDF 會以影像方式輸出。
    這個 PDF 需要密碼

    密碼只用於在本機解開檔案，不會被儲存或傳送。
